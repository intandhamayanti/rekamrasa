# Rekam Rasa Editorial

Buat landing page editorial light-mode untuk brand photobooth rental bernama “Rekam Rasa”.

PENTING:

Saya hanya punya sedikit credit, jadi hasil pertama harus sangat dekat dengan arahan ini.

Tolong revisi dari arah sebelumnya karena hasil yang lama masih terlalu dark, terlalu boxy, dan terlalu banyak section yang dipaksa jadi cards.

Saya ingin hasil yang lebih dekat ke rasa Picnpose, tapi tidak harus copy-paste persis.

Hero boleh lebih eksploratif dan tidak perlu sama persis dengan Picnpose.

ARAH UTAMA:

- light mode, bukan dark mode

- editorial layout

- image-led

- elegant

- premium tapi tetap hangat

- clean

- airy

- refined

- bukan SaaS

- bukan template event organizer

- bukan landing page startup

- bukan AI slop

REFERENSI RASA:

Gunakan rasa visual seperti Picnpose:

- light editorial

- serif headline besar

- sans-serif clean untuk body dan UI

- ritme section seperti editorial spread

- pricing putih bersih

- layout rapi

- penggunaan grid hanya di section yang memang perlu

- tidak semua section harus kotak-kotak

FONT WAJIB:

- Instrument Serif untuk headline besar, section title, emphasis

- Plus Jakarta Sans untuk body, nav, label, button, FAQ, pricing, list

LOGO:

- wordmark text only

- tulis “Rekam Rasa”

- tidak perlu icon

KONSEP BRAND:

Rekam Rasa adalah layanan photobooth rental untuk acara.

Fokus utama:

- wedding

- engagement

- birthday

- corporate event

- brand activation

- gathering

Brand ini juga punya booth aktif di beberapa kota, tapi itu hanya supporting proof, bukan angle utama.

JANGAN:

- jangan dark mode

- jangan ada counter angka di hero

- jangan generate foto dulu

- gunakan placeholder image saja

- jangan bikin semua section jadi kotak-kotak

- jangan pakai section cara kerja

- jangan pakai section booking form

- jangan bikin visual terlalu kaku

- jangan pakai warna krem untuk pricing cards

- jangan highlight custom theme dengan warna berbeda

- jangan bikin testimonial jadi cards kotak

- jangan bikin lokasi booth aktif jadi cards kotak

- jangan bikin coming soon jadi cards kotak biasa
